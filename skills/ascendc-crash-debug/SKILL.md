# ascendc-crash-debug

Scope: local A3 MegaMoe development. Read these repository-owned resources for
this task; no global skill or online lookup is needed.

- [review-debug](../../knowledge/troubleshooting/review-debug.md)
- [window-protocol](../../knowledge/mc2/window-protocol.md)

First bind evidence to one attempt/source/device. Classify host crash, missing progress, device fault or corruption. Preserve logs before cleanup. Test one causal hypothesis using the original reproduction; instrumented experiments are diagnostic only. Report observed cause, alternatives, repair and validation limits.

Use the campaign snapshot and actual target facts. Missing evidence remains
unknown. Foundation and evaluator updates are maintenance work, outside the
candidate edit scope.
