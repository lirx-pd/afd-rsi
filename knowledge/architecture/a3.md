# A3 platform contract

Scope: Ascend910_93 / arch22, baseline for this repository. Device support is
not certified by this document. Obtain the exact SoC, visible logical/physical
mapping, Cube/Vector counts, memory and current software from the target host.
Do not copy nominal hardware counts into tiling. Reject unsupported or unknown
capabilities before consuming CAM work.

arch22 code cannot use arch35-only RegBase/MicroAPI, SIMT, MXFP instructions or
L0C-to-UB paths merely because a newer implementation uses them. An algorithm
can transfer while its instructions, layout, scheduling and ABI cannot.

For mixed kernels distinguish AIC block index, AIV index, task ratio and stage
participants. A phase barrier requires every declared participant, including
cores without useful work. Concurrent streams must fit the actual AIC/AIV
budget together. Record core-start spread before interpreting overlap.

SDK and driver installations are read-only. Record versions and actual build
flags. Discovery and a successful import are not device correctness evidence.
