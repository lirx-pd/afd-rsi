# W4A8 numerical and fusion contract

Scope: homogeneous layered W4A8 routed experts with BF16 output. Preserve the
loaded checkpoint's weight layout, group/channel scales and compensation.
Record W13 and W2 M/N/K, transpose/layout, packing, group sizes and valid expert
counts separately. Shared expert computation remains on Attention for this
campaign scope.

The mathematical route is expert input organization -> gate/up GMM ->
dequantization and compensation -> SwiGLU -> per-token quantization -> down GMM
-> compensation/dequantization -> BF16 and routed scaling -> return layout.
Actual rounding and intermediate dtypes are part of the contract. A BF16 cast
before scaling is not interchangeable with scaling FP32 before the final cast.
Do not introduce clipping, change quantization granularity or reassociate
reductions inside a tiling-only experiment.

First validate packing and each stage with small explainable inputs. Then
compare whole outputs with a frozen trusted implementation. Error tolerances
belong to the campaign and must reflect the numerical operations; a historical
fixture tolerance is not a universal acceptance threshold.

Tile-size edits must reach host tiling, workspace byte formulas, scratch
strides, valid counts and all consumers. Check 0, 1, tile-1, tile, tile+1 and
multiple tiles. A one-tile pass does not establish buffer reuse correctness.
