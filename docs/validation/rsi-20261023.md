summary.status、shutdown_status 保持 failed，campaign 正确拒绝基线。

仅豁免 E2E 已归类为 shutdown 的错误，原始失败日志和 summary 均保留，另行
记录 gate_policy 与 shutdown_errors_ignored。新基线的 build、correctness、service
和两轮 benchmark 均通过，已生成外部提案请求；推理、测试、实际身份和清理
没有被豁免。旧 campaign 和旧判定没有被修改。
